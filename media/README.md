# Media for scheduled posts

Images and videos staged here so the self-hosted Postiz can download them into its media library
(Postiz fetches media from a public URL). Everything here is already public on https://xonomy.open2x.io;
the screenshots show demo data only ("Open2X Demo Bank").

- `xonomy-2026-12/`: December 2026 LinkedIn plan for Xonomy.Open2X. Product screenshots converted from the
  website's WebP files (`xonomy-website/src/assets/img/shots-full/`) to JPG, because LinkedIn accepts JPG/PNG/GIF.
